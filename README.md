## 공통
- `js/fb.js` — Firebase(moaboard-943a3) 연결, 입장 정보, 학생 화면 미리보기(`?preview=반ID` → 이 탭만 학생처럼, 기록을 남기지 않음)
- `js/avatar.js` — 캐릭터 그리기 (`assets/layers/*.png`를 겹치고 색만 바꿈)
- `js/xlsx.js` — 엑셀(.xlsx)·CSV 읽고 쓰기 · `js/ai.js` — AI 문제 만들기 · `js/trash.js` — 휴지통 · `js/questions.js` — 기본 문제
- `js/padkit.js` — 패들렛 도구: 파일 올리기·받기·보기(Firestore에 900KB 조각으로), 이모티콘 반응·고르기, 카드 색, 형식 목록
- `js/emo.js` + `assets/emo/emo.webp` — 모아팡 이모티콘 155개(번호는 바꾸지 않고 뒤에 붙임, 캐릭터 7: 모아·팡팡이·반짝이·몽이·폴짝이·뒤뚱이·딸깍이, 그림은 제미나이). 글에는 `:e12:`처럼 저장하고 그림으로 바꿔 보여 줌. 고르는 창(`openEmoPicker`), 캔버스 말풍선(`drawEmoBubble`). 쓰는 곳: 패들렛 반응(e = 100+번호, 규칙은 299까지)·댓글(고르면 바로 보냄)·글 내용, 가상 교실 채팅·말풍선, 선생님 채팅 기록, 미니 게임 응원 말풍선(emote 100+번호)
- `css/moa.css` — 도트 게임 모양(색·버튼·입력 칸·상자) · `css/brand.css` — 타자팡 ✦ 모아팡 로고, 맨 위 연두 띠, 미리보기 띠

## 다 같이 하는 미니 게임 (선생님 초대)
- 진행판 '학생들 초대하기' → `live/{반}/state/game` 에 `{ id, run, live: 1 }` → 반에 있는 학생 화면이 `games.html?g&run` 으로, 선생님은 `games.html?host={반}&g&run` 으로 넘어감
- 선생님 탭(host)이 판정·🤖를 모두 돌리고 `live/{반}/state/gm` 에 1초에 8번쯤 올림 (h 머리·ro 참가자·t 시계·p 자리·a 상태·g 게임마다·gi 아이템·ev 효과·rk 순위·fin 결과·hb)
- 학생(client)은 자기 캐릭터만 자기 화면에서 움직여 `live/{반}/players/{uid}` 에 올림. 선생님 탭이 학생을 옮기면(대기석·출발선) `tp` 번호로 알림
- 같이 하는 게임: 똥 피하기·술래잡기·달리기·땅따먹기·좀비·폭탄·OX. 보물찾기·채팅·빙고는 각자 하되 선생님이 시작을 누르면 같이 시작
- 반 화면·진행판은 `onLiveState`(js/fb.js)로 `state` 를 받으면서 자주 바뀌는 `gm` 은 뺌
- 보안 규칙은 그대로(선생님 = 반 주인만 `state`·`results` 쓰기, 학생은 자기 `players` 만)

## 데이터
- 퀴즈 세트: `banks/{주인}_lib`(주 선생님 `lib`) `{ sets: [{ id, name, k, list }] }` → 반에 보내면 `classes/{반}.qz[ox|mc]`
- 과제 보관함 패들렛: `boards/*` 중 `cid: 'lib'` → 보낸 패들렛은 반마다 새 보드(`src`: 원래 보드)

## 패들렛 데이터 (boards/{패들렛} 아래)
- `layout`: wall·columns·grid·stream·timeline·canvas (없으면 columns) · `groups`: 격자·스트림·타임라인에서 칸으로 묶을지
- `posts/*`: 함께 쓴 글 `{ sec, title, body, link, img, author, uid, at, files?, color? }` · `comments/*`
- `files/{파일}` `{ name, type, size, n, uid, at }` + `files/{파일}/c/{0..n-1}` `{ d: 바이트 }` — Firebase 무료 요금제라 Storage 대신 Firestore에 저장 (한 파일 10MB, 전체 무료 저장 1GB 안에서)
- `reacts/{글}_{uid}_{번호}` `{ pid, e, uid }` · 캔버스 `pos/{글}` `{ x, y, uid }` · `links/*` `{ a, b, uid, at }`
- 가져온 글(`parts`)에도 `files`·`color`가 붙을 수 있음 (선생님만 고침)

## 그림
모든 그림은 제미나이로 만든 것(`assets/`). 코드는 버튼·글자·반투명 표시만 그린다. 앉은 모습은 옷 입은 서 있는 그림의 윗몸 + 맵 그림에서 의자 등받이·책상 윗면을 다시 그려 덮는다.
