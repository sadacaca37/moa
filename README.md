# 모아팡

김은경 선생님의 방과후 수업 홈페이지 — https://moapang.kr

## 화면
| 파일 | 하는 일 |
|---|---|

| `games.html` | 미니 게임 10가지, 문제 만들기, 탈락하면 대기석(놀이터 아래 마당·OX 관중석)에 앉아 응원 |
| `board.html` | 패들렛 함께 쓰기: 학생·선생님이 글·사진(작게 줄여 저장)·댓글을 올림, 자기 글 지우기, 선생님은 모두 지우기·글쓰기 잠그기 |
| `teacher.html` | 선생님 화면: 반 만들기, 방번호·QR, 진행판(교실 화면, 수업 시작, 맵, 공지, 퀴즈, 게임), 📚 퀴즈 보관함(세트 만들기 → 반 골라 보내기), 👀 학생 화면 미리보기, 첫 화면 꾸미기 |
| `padlet.html` | 내 패들렛·과제방: 📦 과제 보관함, 🚀 여러 반에 보내기, 패들렛 CSV·엑셀 가져오기, 보드 고치기, 학생에게 보이기, 학생 글쓰기 잠그기, 다른 패들렛으로 복사, 🗑 휴지통(30일 뒤 영구 삭제) |

## 공통
- `js/fb.js` — Firebase(moaboard-943a3) 연결, 입장 정보, 학생 화면 미리보기(`?preview=반ID` → 이 탭만 학생처럼, 기록을 남기지 않음)
- `js/avatar.js` — 캐릭터 그리기 (`assets/layers/*.png`를 겹치고 색만 바꿈)
- `js/xlsx.js` — 엑셀(.xlsx)·CSV 읽고 쓰기 · `js/ai.js` — AI 문제 만들기 · `js/trash.js` — 휴지통 · `js/questions.js` — 기본 문제
- `css/moa.css` — 도트 게임 모양(색·버튼·입력 칸·상자) · `css/brand.css` — 타자팡 ✦ 모아팡 로고, 맨 위 연두 띠, 미리보기 띠

## 데이터
- 퀴즈 세트: `banks/{주인}_lib`(주 선생님 `lib`) `{ sets: [{ id, name, k, list }] }` → 반에 보내면 `classes/{반}.qz[ox|mc]`
- 과제 보관함 패들렛: `boards/*` 중 `cid: 'lib'` → 보낸 패들렛은 반마다 새 보드(`src`: 원래 보드)

## 그림
모든 그림은 제미나이로 만든 것(`assets/`). 코드는 버튼·글자·반투명 표시만 그린다. 앉은 모습은 옷 입은 서 있는 그림의 윗몸 + 맵 그림에서 의자 등받이·책상 윗면을 다시 그려 덮는다.
